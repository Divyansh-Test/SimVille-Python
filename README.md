# SimVille-Python

A multi-agent simulation written in Python, where agents interact and make decisions in a shared simulated world.

## Goal

The goal of SimVille-Python is to create a simulation that models the real world to some extent. It is intended to explore how multiple agents can coexist, interact, and influence the state of a simulated environment.

## AI-Driven Decisions

All decisions in the simulation are made by an AI that is trained especially for this use case. Rather than relying entirely on manually scripted behavior, the project gives its trained AI responsibility for deciding how agents behave and respond within the simulation.

## Project Status

This is the very initial version of the project. The simulation is still at an early stage, and its design, agent behaviors, training approach, and world model may change significantly as development continues.
